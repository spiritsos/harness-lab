# 도메인 규칙

## 주문 상태

```
PENDING ──결제──▶ PAID ──출고──▶ SHIPPED ──배송완료──▶ DELIVERED
                   │
                   └──취소──▶ CANCELLED
```

- 취소는 **PAID 상태에서만** 허용한다. PENDING(미결제)은 자동 만료로 처리하고, SHIPPED 이후는 반품 절차로 처리한다.
- 취소 시 `cancelled_at`에 취소 시각을 기록한다.

## 금액

- 모든 금액(`price`, `unit_price`, `total`)은 **원 단위 정수(int)**. 소수점이 생기면 안 된다.
- 할인 쿠폰 금액은 원 단위로 **내림**한다. (예: 9,990원의 10% 할인 → 999원 할인 → 8,991원)

## 주문 번호

- 형식: `A-0000` (A- 뒤 4자리 숫자). 내부 id와 별개로 외부에 노출하는 식별자다.
- API 경로와 응답에는 항상 order_no를 쓰고, 내부 id는 노출하지 않는다.
